# Security Policy

## Supported versions
Runnelon is in early development and is **not production-ready**. No stable release line is currently supported.

## Reporting vulnerabilities
**Do not open public GitHub issues for undisclosed vulnerabilities.** Use GitHub's private vulnerability reporting feature if enabled for this repository. If it is not enabled, contact maintainers through a private channel listed on the GitHub organization profile; do not disclose exploit details publicly.

Please include affected commit/version, reproduction steps, impact, and suggested mitigation if available. Do not include live credentials or personal data.

## Disclosure
Maintainers will triage reports and coordinate disclosure when a secure reporting channel and release process are established. No response SLA is promised at this stage.
